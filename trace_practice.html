ステップ0：約束事

これを飛ばすと全部わからなくなる。最初に3つだけ。

  1. ← は「＝」ではない。「右側を計算して、左の箱に入れる」という命令。
    x ← 5 は「5 を x の箱に入れる」。
    x ← x ＋ 1 は「今の x に 1 足して、x の箱に入れ直す」。数学の式として読むと「x＝x＋1」は成立しないので詰まる。式ではなく命令。
  2. 変数＝名前のついた箱。中身は上書きされる（前の値は消える）。後の行で使う値は、必ず「上書き後の最新の値」。
  3. トレース＝1行ずつ実行して、箱の中身を書いていく作業。頭の中でやらない。紙に表を書く。

擬似言語 → 日本語の言い換え

c ← c ＋ 1→c を1つ増やす（＝回数を数える） s ← s ＋ i→s に i を足し込む（＝合計を作る） t ← a→a の中身を t にコピーしておく（＝一時退避） n mod 3→n を 3 で割った余り（7 mod 3 ＝ 1） n ÷ 2→整数どうしなら小数点以下は切り捨て（7 ÷ 2 ＝ 3） x が 0 と等しい→x ＝ 0 か？（条件として使う） x が 0 以下→x ≦ 0 か？

ステップ2：if（分かれ道）

if (条件)
  ○○
else
  △△
endif
  • 条件が成り立つ（真）なら ○○ だけ実行、△△ は飛ばす
  • 成り立たない（偽）なら △△ だけ実行
  • endif は「分かれ道おわり」の印。ここから先はどちらの道でも実行する
  • else が無いときは、偽なら何もしないで endif の次へ
  • elseif は「最初の条件が偽だったら、次の条件を見る」。上から順に見て、最初に真になった1つだけ実行

ステップ3：for（回数の決まったくり返し）

for (i を 1 から 3 まで 1 ずつ増やす)
  ○○
endfor
  • 3つのダイヤルで決まる：①スタート（1から）②ゴール（3まで）③刻み幅（1ずつ）

ステップ5：while（条件が成り立つ間のくり返し）

while (条件)
  ○○
endwhile
  • for は「何回やるか」が最初から決まっている。while は「条件が成り立つ間ずっと」
  • 毎回、中身に入る前に条件を判定する。偽になった瞬間に endwhile の次へ抜ける
  • 抜けるときも判定は1回やっている（中身は実行しない）。表に「偽 → 抜ける」の行を必ず書く
  • 中身の中で条件に関係する変数を変えないと、永遠に終わらない（無限ループ）

練習 5-3（前判定と後判定）

同じ数字で、判定の位置だけ違う2つを比べる。

【A：前判定】          【B：後判定】
n ← 5                  n ← 5
c ← 0                  c ← 0
while (n ＜ 5)          do
  n ← n ＋ 1              n ← n ＋ 1
  c ← c ＋ 1              c ← c ＋ 1
endwhile               while (n ＜ 5)
問：A と B、それぞれ最後の c は？
答：A は c ＝ 0、B は c ＝ 1

A（前判定）：入る前に判定 → 5＜5 は偽 → 1回も入らない → c ＝ 0

B（後判定 do〜while）：まず1回やってから判定 → n＝6、c＝1 → 6＜5 は偽 → 抜ける → c ＝ 1

ポイント：do … while は「最低1回は必ず実行」。違いはそれだけ。判定の位置を見て、どちらの型か最初に確認する。

本番のコツ

  1. 最初に約束事を確認する。「要素番号は 1 から」「÷ は切り捨て」など、問題文の冒頭に書いてある。
  2. 表を書く。頭の中でやらない。列は「変数の名前」＋「判定の結果」。くり返しは1回＝1行。
  3. くり返しに入る前に、i の値を全部書き出す（2,4,6,8,10 など）。ダイヤル3つ（スタート・ゴール・刻み）を読み違えると全部ずれる。
  4. while は「偽 → 抜ける」の行まで書く。判定回数と実行回数は1つ違う。
  5. 空欄は選択肢を全部入れて動かす。要素3〜4個の小さい配列を自分で決めて試す。「正しそう」で選ばない。
  6. 境界を疑う。「n まで」か「n－1 まで」か、「＜」か「≦」か。data[i＋1] があるなら最後は n－1。
  7. return は即終了。くり返しの途中でも、そこで関数は終わる。
  8. 分からない問題は飛ばす。科目B は 20 問・100 分。1問5分。トレースで解ける問題（今日の型）を確実に取る。再帰・ハッシュ・木構造は後回しでよい。
